# RealSnap Web App — B안 Prototype

리얼스냅 웹앱 리뉴얼 시안(12개 화면)을 서로 연결한 클릭 프로토타입이에요.

## GitHub Pages로 올리기
1. GitHub에서 새 저장소 만들기 (예: `realsnap-prototype`)
2. 이 폴더 안의 파일을 그대로 올리기 — `index.html`, `fonts/`, `.nojekyll`
   - 웹에서 올릴 때: Add file → Upload files → 폴더 내용 전체 끌어놓기 → Commit
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1–2분 뒤 `https://<계정>.github.io/realsnap-prototype/` 에서 열려요

## 쓰는 법
- 사이드바·카드·버튼을 누르면 해당 화면으로 이동해요.
- 오른쪽 아래 **Screens**: 화면 목록, 맨 아래 "Show all screens"는 12개 화면을 한 번에 펼쳐요(Figma 가져오기용).
- 화면별 주소: `#home`, `#create`, `#mood-canvas`, `#lookbook`, `#lookbook-menu`, `#library`, `#assets`, `#pricing`, `#help`, `#home-dark`, `#account`, `#workspace`, `#all`
